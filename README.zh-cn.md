# 关于此博客

Choose a Language/选择语言: [English ver](./README.md), 中文版 (此处)

这是托管在https://blog.mikufancx.cyou 的博客的源配置

如果域名发生变化，你可以访问替代的URL，https://mikufancx-blog.vercel.app/

## 开发/测试该博客

运行`mise run dev`来在本地预览博客。

或者，使用`mise run dev --prod`来在本地预览中启用评论系统。

## 发布博客

运行`mise run generate --prod`生成博客的静态HTML文件，并保存在`./public`文件夹下（或者使用`mise run generate`生成包含草稿的本地/测试版本）。
